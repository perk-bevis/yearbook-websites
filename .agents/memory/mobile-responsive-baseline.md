---
name: Mobile responsive baseline
description: Product-specific expectation for usable yearbook layouts on phones.
---

Yearbook pages should adapt to narrow phone screens instead of shrinking desktop layouts. Navigation must stay readable and switch to a mobile pattern; page headings, cards, controls, and spacing should fit without tiny text or horizontal clipping.

**Why:** The user reported a phone screenshot where the desktop navigation was compressed into tiny links and asked for responsive behavior.

**How to apply:** When changing yearbook UI, verify at phone widths (roughly 360–430 CSS pixels), paying attention to navigation, card width, typography, and controls near screen edges.
